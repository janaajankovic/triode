# Engineering standards

The baselines Triode is held to, and what enforces each one. **Tool** means the build or the PR pipeline fails;
**Review** means the pull-request review (pr-reviewer agent and maintainer) checks it against this page.
A change that needs to break a rule proposes an ADR first.

| Baseline | Enforced by | How |
|---|---|---|
| **API security: [OWASP ASVS 5.0](https://owasp.org/www-project-application-security-verification-standard/) Level 1** | Review, partly Tool | Every API story checks the L1 requirements it touches: input validation, authentication and access control, error handling without internals, logging without personal data. Secrets and vulnerable dependencies are caught by the tools below. |
| **AI features: [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)** | Review | Every LLM call goes through `LlmGateway`. Prompts are versioned files. Model output is validated as structured output before use and never executed or trusted as instructions (prompt injection, improper output handling). Ticket data sent to the model is kept to what the task needs (sensitive information disclosure). Token and retry limits are set (unbounded consumption). |
| **Secrets** | Tool + Review | gitleaks scans the full git history in the first pipeline step. No keys, tokens or passwords in code or config. Local defaults are throwaway values matching `docker-compose.yml`. A real leak is rotated first, then removed. History is never rewritten to hide a false positive (that goes in `.gitleaksignore` with a reason). |
| **Dependencies** | Tool | Trivy fails the PR on HIGH or CRITICAL vulnerabilities in compile/runtime dependencies. Accepted findings go in `.trivyignore.yaml` with a `statement` (reason) and an `expired_at` (review date, at most 90 days ahead). The Maven wrapper checks the SHA-256 of the wrapper jar and the Maven distribution. CI images are pinned by version and digest. |
| **Clean code** | Tool + Review | Spotless (Palantir format) runs in `validate`. Main code compiles with `-Xlint:all -Werror` and Error Prone, so any javac or Error Prone warning fails the build ("no new warnings"). The review checks naming, small methods and readable tests. |
| **API design** | Review | Errors are [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457) problem details from one global exception handler. The OpenAPI description is generated by springdoc and kept accurate. Paths are versioned under `/api/v1`. Records are used as DTOs. |
| **Test quality** | Tool + Review | JaCoCo fails the build if any `dev.triode.*.domain` package is below 80 % line coverage. The review checks that tests assert behaviour (not implementation) and cover edge cases, and that persistence and HTTP are tested against real Postgres (Testcontainers). |
| **Architecture** | Tool + Review | `ModularityTests` (Spring Modulith): modules only use each other's `api`. `ArchitectureTests` (ArchUnit): `domain` is pure Java. ADRs in `docs/adr/` record decisions, and the review asks for one when a change departs from them. |

## Gate exceptions

None. No lint category or Error Prone check is disabled. Test code is compiled without `-Werror` and Error Prone on
purpose; the gates cover production code. Any future exception is listed here with its reason.

## Tool choices (checked 2026-11-18)

- **Static analysis: Error Prone 2.52.0.** It runs inside javac on JDK 25, so its findings fall under `-Werror` and
  cost no extra build step. SpotBugs 4.10.5 also supports Java 25, but it would add a second, slower bytecode pass
  whose findings largely overlap Error Prone's, so it isn't added.
- **Dependency scan: Trivy 0.76.2** (`trivy fs` on `backend/`). It reads `pom.xml`, resolves parents, BOMs and
  transitive dependencies (verified: the same 121 runtime packages as `mvn dependency:list`), and needs no account or
  token. OWASP Dependency-Check was not chosen because it needs an NVD API key in practice.
- **Secret scan: gitleaks 8.30.1.**
- **Pinned images:** images are pinned by digest as well as tag, so a re-pushed or tampered tag cannot change what
  runs. This happened to Trivy's own Docker Hub tags in March 2026
  ([GHSA-69fq-xp46-6x23](https://github.com/aquasecurity/trivy/security/advisories/GHSA-69fq-xp46-6x23)). To update
  an image, change its tag and digest together, after checking the digest with `docker buildx imagetools inspect`.
